# 应用街

按需求找工具，了解用途与优缺点，直达应用官网。

当前版本收录 **1,291 个应用及网站服务**。压缩没有删减应用、简介、优缺点或分类数据，也没有缩小图标尺寸、裁切或拉伸 Logo。

## 打开网站

直接用较新的 Chrome、Edge 或 Safari 打开 **index.html**，即可浏览和搜索。打开时会显示正常的加载提示，加载完成后自动进入首页，不额外增加等待时间。

网页使用浏览器原生解压功能。界面和应用资料已打包进 HTML；外部官网及未内嵌的图片仍需要网络。直接打开文件的方式不能使用 Google 登录与邮件发送。

## 主要功能

- **按需求搜索**：输入应用名称、缩写或想完成的任务；按回车搜索，点击清除按钮清空输入。
- **分类与筛选**：按用途浏览，并结合费用标签缩小范围。
- **今日精选与排行榜**：查看精选工具，以及沿用的 01–10 分类排行。
- **应用详情与比较**：查看能做什么、优点和使用限制，最多同时比较三个应用。
- **外观设置**：切换字体、界面语言和主题；品牌名称保持独立设计。
- **历史记录**：在当前浏览器查看搜索历史。
- **反馈建议**：填写评分与建议；可选择署名，署名时姓名必填，对外显示为“姓****”。

费用标签用于区分免费、部分付费和付费等使用方式，具体功能、价格及地区限制请以应用官方信息为准。排行榜与精选属于网站整理的导航内容，不代表实时下载量统计。

## Google 登录与发送反馈

登录和 Gmail 发信代码已接入，但还需要填写有效的 Google OAuth 凭据。**接入完成不等于账号已配置或真实邮件已投递。**

1. 按 [Google登录配置说明.md](Google登录配置说明.md) 设置 Google 项目和回调地址。
2. 在同一文件夹的隐藏文件 **.env** 中填写 Client ID 和 Client secret。已有 .env 时请直接编辑，不要用模板覆盖。
3. 双击 **启动应用街.command**，保持终端窗口开启。
4. 在浏览器打开 **http://localhost:8787**，进入反馈建议后登录 Google 账号。
5. 确认反馈内容，再点击发送。登录本身不会发送邮件。

启动程序需要 Node.js 22 或更新版本，也支持本机现有的 Codex Node 运行时。修改 .env 后需要重启服务。

反馈收件地址固定为 **getyingyongjie@gmail.com**。取消署名只隐藏评价姓名，收件人仍能看到发件邮箱。草稿和发送成功后的本机副本保存在当前浏览器，不会自动发布为所有访客可见的评价。

## 压缩与图像清晰度

当前 index.html 约 **24.48 MB**，运行文件压缩包约 **18.6 MB**，均低于 25 MB。大小随后续更新可能变化。

图像采用无损或质量 97 的 WebP 编码，保留原始宽高、比例及透明通道。已进行图标对照和压缩版网页运行检查；这不意味着所有图片都属于逐像素无损。未处理的原始图像资源保留原编码。

## 使用与更新说明

- 刷新后页面回到顶部；历史和偏好依赖当前浏览器的本地存储，清除网站数据或使用隐私窗口可能无法保留。
- file://、localhost 和公开网址的数据互相隔离，不会自动迁移历史记录或草稿。
- 更新时替换同一位置的 index.html；本机 .env 请自行保留。若已启动服务，更新后刷新页面，配置变化则重启服务。
- 给其他人使用 Google 登录时，需要部署支持 Node.js 的 HTTPS 网站，并配置对应域名与 Google 授权。只上传 HTML 到静态托管，无法提供登录和发信接口。
- 官网按钮打开第三方网站，不直接安装应用。应用名称、图标及商标属于各自权利人；收录不代表官方合作。

## 遇到问题

加载失败时，先确认使用的是较新的浏览器和完整的 index.html 文件。登录不可用时，请按配置说明检查 .env、启动地址与 Google 回调地址是否一致。

反馈问题时，请附上应用名称、操作步骤和截图，便于定位。
